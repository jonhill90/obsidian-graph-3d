# Agent rules for this repository

This repository is the Graph 3D plugin for Obsidian: `main.js`, `styles.css`, `manifest.json` and `versions.json`, with its documentation in `README.md` and `IMPORT.md`.

## Docs or notebook?

Before saving, ask: is it about this plugin, saying why it is so, what it is, or how to install, use, build, release or change it?

- **Yes:** it is documentation. It goes here by pull request: `README.md` for users, or a `docs/` folder once a page outgrows the README. A change that alters how the plugin behaves or is released updates its doc in the same PR.
- **No, or still working material:** it is what agents learned (research, benchmarks, measurements, notes, thinking). It goes in the agent notebook, `jonhill90/agent-notebook`, which may link here but never copies these docs.

This repository holds the public, polished version. Once a finding about the plugin is measured or sourced, its polished form goes in the docs here by a pull request the owner sees, with its own sources. Nothing here links into the notebook, which is private.
